# نظرة معمارية — احجز تأشيرتك

## الفكرة العامة

المشروع مبني بـ Next.js App Router بحيث تكون كل صفحة عامة (الرئيسية، صفحات الدول، الأسعار...) قابلة للتصيير الساكن
(Static/SSG) قدر الإمكان لتحسين الأداء وSEO، بينما الصفحات الشخصية (لوحة العميل، لوحة التحكم) تُبنى لاحقًا كصفحات
محمية تتطلب مصادقة عبر Supabase Auth.

## طبقات المشروع

1. **طبقة العرض (UI)** — `components/ui/*`: مكوّنات أساسية بأسلوب shadcn/ui (زر، بطاقة، حوار، تبويبات...) مبنية
   يدويًا فوق Radix UI + class-variance-authority لضمان الاتساق البصري (الهوية: كحلي + ذهبي).
2. **مكوّنات الميزات** — `components/{home,wizard,documents,dashboard,country,admin,appointments}`: تجمع مكوّنات
   UI الأساسية في تجارب كاملة لكل قسم من أقسام المنصة.
3. **طبقة البيانات** — `lib/data/*`: المصدر الحالي (المرحلة MVP) لكل المحتوى شبه الثابت (الدول، أنواع التأشيرات،
   الأسعار، الأسئلة الشائعة). هذه الطبقة مصممة لتُستبدل تدريجيًا باستعلامات Supabase دون تغيير الأنواع في
   `types/index.ts`.
4. **طبقة الاتصال بقاعدة البيانات** — `lib/supabase/{client,server}.ts`: عملاء جاهزون (متصفح/سيرفر) يعملان فور
   تعبئة متغيرات البيئة، دون الحاجة لأي تعديل بنيوي إضافي.
5. **قاعدة البيانات** — `database/{schema,policies,seed}.sql`: تصميم كامل لجميع الجداول المذكورة في المواصفات مع
   Row Level Security تمنع أي عميل من الوصول لبيانات عميل آخر.

## تدفق طلب التأشيرة (User Flow)

```
الصفحة الرئيسية → اختيار الدولة/الوجهة → صفحة الدولة (المتطلبات)
   → ابدأ طلب التأشيرة (Wizard: الجنسية → الدولة → نوع التأشيرة → بيانات المسافر → العائلة → المراجعة)
   → رفع المستندات (فحص أولي لنوع/حجم/وضوح الملف)
   → لوحة العميل "ملفي" (متابعة حالة الطلب عبر 8 خطوات)
   → توجيه لرابط التقديم/الحجز الرسمي (لا حجز آلي بدون API رسمي)
```

## القرارات التصميمية المهمة

- **لا حجز مواعيد آلي**: صفحة `/appointments` توجّه المستخدم لرابط الحجز الرسمي فقط، ولا تخترع مواعيد أو تتجاوز
  أنظمة الحماية/الكابتشا الخاصة بالجهات الرسمية.
- **فصل الرسوم**: كل حساب (Invoice) يفصل `service_fee` عن `government_fee` بوضوح في قاعدة البيانات وفي الواجهة.
- **دولة شنغن الصحيحة**: مكوّن `SchengenHelper` يطبّق قاعدة "أطول إقامة ثم أول دخول" بدلاً من ترك المستخدم يختار أي
  دولة شنغن عشوائيًا.
- **إخلاء المسؤولية القانوني**: مكرر عمدًا في التذييل، الصفحة الرئيسية، صفحة "من نحن"، وكل صفحة دولة، لضمان عدم
  الادعاء بأن المنصة جهة رسمية أو تضمن قبول التأشيرة.
